# Superflix

Projeto de estudo e portfólio para desenvolvimento de uma plataforma de catálogo de filmes, com foco em backend Java, integração com banco de dados, conteinerização e práticas DevOps.

## Objetivo

Construir uma aplicação web para gerenciamento e consulta de filmes, evoluindo gradualmente de uma API simples para uma aplicação com frontend, banco de dados, infraestrutura conteinerizada e pipeline de integração contínua.

## Tecnologias

### Implementação inicial
- Java
- Spring Boot
- Maven
- MySQL 8
- Docker

### Planejadas para as próximas etapas
- React
- Nginx
- Docker Compose
- GitHub Actions
- Testes automatizados
- Implantação em nuvem

> As tecnologias planejadas serão atualizadas conforme forem efetivamente integradas ao projeto.
